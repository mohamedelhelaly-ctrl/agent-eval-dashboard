
# Agent Evaluation Dashboard: Project Plan

## 1. Task Description

Compare several versions of one AI agent on one job, using the same test questions and the same measurements, so that differences in results can be traced to what changed in the agent.

**The job:** a data analyst agent. It receives a natural-language business question (for example, "What was the churn rate in Q1 2025?"), explores a database, looks up business definitions, queries the data, and returns a single answer that can be checked automatically.

**What is held constant across all agent versions:** the task, the database, the tools, the glossary, and the eval set.

**What varies between agent versions:** the model and the prompt (see section 4). Only one of these is changed at a time against a baseline, so any change in results has one cause.

**Purpose of the evaluation:** show which agent version is best for a given balance of accuracy, cost, and speed, and where each version fails.

## 2. Dataset / Database Design

A synthetic SaaS company database in SQLite, generated by `generate_db.py` with a fixed seed (42) so it is identical on every run. "Today" for all questions is 2026-01-01, and the data covers 2023-01-01 to 2025-12-31.

### Tables

| Table | Key columns | Purpose |
|---|---|---|
| `customers` | customer_id, company_name, country, industry, signup_date, acquisition_channel, is_test_account | Who the customers are |
| `plans` | plan_id, plan_name, legacy_name, monthly_price, annual_price | Four tiers: Starter, Pro, Business, Enterprise |
| `subscriptions` | subscription_id, customer_id, plan_id, billing_cycle, start_date, end_date, status, cancel_reason | Each plan period for a customer |
| `invoices` | invoice_id, subscription_id, customer_id, invoice_date, amount, status, refunded_amount | Billing history |
| `support_tickets` | ticket_id, customer_id, created_at, resolved_at, priority, category, csat_score | Support activity |
